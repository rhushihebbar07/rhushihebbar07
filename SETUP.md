# RHUSHI HEBBAR — GitHub Profile

This package is structured to be used as the profile repository:

`rhushihebbar07/rhushihebbar07`

## Included

- `README.md` — complete profile in the same overall style as the supplied reference
- `assets/header.svg` — custom Rhushi HUD header
- `assets/now.svg` — custom current-operations panel
- `.github/workflows/3d-profile.yml` — generates the 3D contribution calendar
- `.github/workflows/activity-graph.yml` — generates activity graph output
- `.github/workflows/pacman.yml` — generates the Pacman contribution graph

## Upload

Put all files into the root of:

`https://github.com/rhushihebbar07/rhushihebbar07`

Commit to the branch used by your profile repository (normally `main`).

Then open GitHub → Actions and run the workflows manually once.

## Important

The 3D contribution SVGs are generated by GitHub Actions, so the `profile-3d-contrib/`
folder does not contain another user's contribution data.

The README uses your GitHub username throughout:
`rhushihebbar07`
