# Rhushi Hebbar — Cinematic README

## Direction

This version treats the GitHub profile as a cinematic sequence:

1. Boot — distant character enters.
2. Reveal — name/title appears.
3. Identity — character pauses while the story is introduced.
4. Toolkit — character works at a terminal.
5. Projects — camera moves with the character.
6. Telemetry — GitHub signal appears.
7. Journey — character moves toward the next chapter.
8. Finale — character exits and the transmission closes.

### Important GitHub limitation

GitHub Markdown cannot detect the visitor's scroll position or trigger JavaScript scroll animations. Therefore this package uses large autoplaying GIF scenes as cinematic scroll checkpoints. The visual result is designed to feel like a film as the reader moves down the page.

## Install

Copy `README.md` and the entire `assets/` folder into your profile repository.
