# Rhushi Hebbar GitHub Profile README

## Install

Copy the contents of this folder into the profile repository:

    rhushihebbar07/rhushihebbar07

The repository should contain:

- README.md
- .github/workflows/3d-contributions.yml
- .github/workflows/snake.yml

## Important

The README intentionally uses remote animated services for the hero/coding visuals and stats.
The 3D contribution calendar and contribution snake are generated by GitHub Actions.

After pushing the files, open the repository's Actions tab and run both workflows manually once.
They will then update their generated assets on schedule.
